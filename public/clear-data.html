🗑️ Clear PropXchain Data

⚠️ Warning: This will permanently delete all local data including transactions, users, and documents.
📝 What will be cleared:
  • All transactions
  • User data and authentication
  • All uploaded documents
  • Saved wizards
✅ All local data has been cleared! You can close this page and start fresh.
🔧 To clear blockchain data:

Run these commands in your dfx terminal:

dfx canister install transaction_manager --mode reinstall
dfx canister install user_management --mode reinstall
dfx canister install property_registry --mode reinstall
dfx canister install document_storage --mode reinstall
