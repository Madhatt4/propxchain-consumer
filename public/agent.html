PropXchain

Connect PropXchain to your AI assistant.

PropXchain has a hosted MCP server. Add one URL to Claude, ChatGPT, Cursor or any MCP client, approve with your email, and your assistant can read and progress your UK property transaction alongside you. Nothing to install.

Step 1

Add the connector

The PropXchain MCP server URL:

https://mcp.propxchain.com/mcp
  • claude.ai or Claude Desktop: Settings, Connectors, Add custom connector. Paste the URL and leave the client ID and secret blank.
  • Claude Code: run the command below.
  • ChatGPT, Cursor and other MCP clients: add a remote (Streamable HTTP) MCP server with the URL above. Sign-in is OAuth 2.1, discovered automatically.
claude mcp add --transport http propxchain https://mcp.propxchain.com/mcp
Step 2

Approve with your email

Your AI app opens auth.propxchain.com. Enter your PropXchain email and the 6-digit code we send you. The connection lasts 30 days, and you can remove it at any time.

Step 3

Use it on a transaction

Open any of your transactions on propxchain.com and click Get AI assistance. You'll get a prompt with that transaction's invite code to paste into your assistant. It calls propxchain_join_transaction_as_bot, reads the transaction state, and walks you through what's outstanding. Any party can remove the assistant from the transaction's bot panel.

Your AI app can't add a remote MCP server? Run it locally instead.

Install the stdio server (Node.js 20+), which generates its own keypair on first launch:

npm install -g @propxchain/mcp-server

Then add it to your host's config under mcpServers. For Claude Desktop the file is %APPDATA%\Claude\claude_desktop_config.json on Windows, ~/Library/Application Support/Claude/claude_desktop_config.json on macOS, ~/.config/Claude/claude_desktop_config.json on Linux. Fully quit and relaunch afterwards.

{ "mcpServers": { "propxchain": { "command": "propxchain-mcp-server", "env": { "IC_NETWORK": "ic" } } } }

What this gives the agent

Nineteen tools across the conveyancing flow:

  • Self-register against a transaction via invite code
  • Read transactions and their on-chain status
  • Check document proofs and their verification state
  • Read property registry data
  • Check phase progress and outstanding milestones
  • Get explainers for the legal or technical jargon a buyer or seller will encounter

The bot identity only has access to the transactions you've granted it via invite code. It can't see anything else, can't transfer funds, and can't sign on your behalf.
